# my-sysadmin-scripts

# Скрипт мониторинга Linux

Скрипт [script.sh](script.sh) раз в N секунд снимает free -h, df -h, uptime и дописывает в `monitor.log` блок из этих трёх выводов с временной меткой в начале.
<br>Формат вывода:
<br>--- 2026-08-15 14:03:00 ---
<br>free -h
<br>df -h
<br>uptime
<br>Пример в [README.md](README.md)

## Принцип работы

1. Определяется полный путь к `monitor.log` в текущей рабочей папке.
2. Если файл отсутствует, скрипт создаёт его и сообщает путь в консоли.
3. При ошибке создания скрипт завершается с кодом `1`.
4. В бесконечном цикле записываются временная метка и вывод трёх команд.
5. После каждого блока выполняется пауза `N` секунд.

`N=5` задано в скрипте. Интерактивный ввод не требуется.
Существующие записи сохраняются благодаря перенаправлению `>>`.

## Использование

- Запуск: `bash script.sh`
- Остановка: `Ctrl+C` в терминале, где запущен скрипт.

## Особенности

- Первый замер выполняется сразу.
- Интервал между получением метрики N секунд.
- Файл растёт до остановки скрипта.
- Проверка наличия файла выполняется один раз перед циклом и если его нет, то создает его и выводит в консоль путь до него.
